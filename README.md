# LYRA — умное зеркало для мониторинга состояния астронавта

Прототип для NASA Space Apps Challenge. Утренняя проверка за ~45 секунд: камера анализирует лицо и осанку,
станция ладони измеряет пульс, SpO₂, температуру и силу хвата. Результат сравнивается с **личной нормой**
и выводится на зеркало: 🟢 стабильно / 🟡 повторить / 🔴 возможное отклонение — с объяснением простым языком.

> Это система скрининга и самоконтроля, **не медицинское устройство и не диагноз**.

План работы на хакатоне — [PLAN.md](PLAN.md).

## Быстрый старт (без камеры и железа)

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m lyra.server --sim
```
Открыть http://127.0.0.1:8000 → нажать **3** (сценарий «день 40») → **Пробел** (проверка) → **T** (тренды).

## Режимы запуска

| Команда | Камера | Ладонь |
|---|---|---|
| `python -m lyra.server --sim` | симуляция | симуляция |
| `python -m lyra.server --palm-sim` | настоящая | симуляция |
| `python -m lyra.server --palm-port /dev/cu.usbserial-0001` | настоящая | ESP32 |

Флаги: `--fast` — короткие фазы для отладки, `--camera 1` — другая камера, `--scenario day40`, `--db lyra.db` — сохранять историю в файл.
Порт ESP32 на Mac: `ls /dev/cu.*`.

**С настоящей камерой первым делом нажмите `C` (калибровка):** система измерит вас и построит
смоделированную историю вокруг ваших значений. Иначе ваши реальные показатели сравниваются с чужой «нормой».

## Управление панелью

| Клавиша | Действие |
|---|---|
| Пробел / Enter | начать проверку |
| C | калибровка |
| 1 / 2 / 3 | сценарий: день 1 / день 20 / день 40 (с отклонением) |
| T | тренды за полёт |
| Esc | прервать измерение |

Кнопки в нижней части экрана — то же самое мышью (появляются при наведении).

## Как устроено

```
lyra/
  core/       metrics.py — справочник метрик · assess.py — личная норма и статусы
              db.py — SQLite · engine.py — сборка результата
  vision/     face.py — отёк лица, моргание, PERCLOS, зевота (MediaPipe Face Mesh)
              pose.py — плечи, голова (MediaPipe Pose) · rppg.py — пульс по видео (POS)
              capture.py — сканирование 20 с
  palm/       reader.py — чтение ESP32 по Serial · firmware/lyra_palm/ — прошивка Arduino
  sim/        history.py — синтетическая история: 7 дней до полёта + дни полёта
  dashboard/  панель зеркала (HTML/JS, без сборки)
  server.py   FastAPI + WebSocket
docs/drawings/  чертежи: зеркало, станция ладони, схема проводки
tests/          pytest
```

**Логика статуса.** Личная норма — среднее и σ последних 14 измерений (минимум 7, до этого — общий диапазон).
`z = (значение − норма) / σ`, учитывается только опасное направление (например, падение силы хвата).
|z| < 2 → 🟢, 2–3 → 🟡, ≥ 3 или две 🟡 → 🔴. Измерение плохого качества не влияет на статус — просим повторить.

**Главная «космическая» метрика — отёчность лица.** Ширина лица на уровне скул и щёк, делённая на
межзрачковое расстояние (кости не отекают — это «линейка»). Отслеживает перераспределение жидкости к голове
в невесомости.

## Честность на демо

История за дни до текущего — смоделирована (`lyra/sim/history.py`), панель это подписывает.
Не заявляйте измерение плотности костей, диагнозы или «определение психического состояния».
