# LYRA — архитектура веб-демо (1 страница)

```
data/nasa_reference.json ──(только чтение, перечитывается при изменении)──┐
                                                                          ▼
 lyra/core ─ чистая логика, без HTTP и без случайности                 reference.py
   metrics.py   инженерные параметры метрик (группа, опасное направление, шум, советы)
   expected.py  модель «ожидаемой адаптации» NASA → коридор по дням (linear / saturating / none)
   assess.py    статус = личная норма (z, с поправкой на траекторию NASA) ⊕ выход за коридор
   engine.py    сеанс → статусы, общий итог, параметры 3D-облака
   store.py     сеансы и дозы в памяти (узкий интерфейс → легко заменить на БД)
   comms.py     очередь передачи на Землю: задержка из справочника, статусы «в пути/доставлено»
 lyra/sim ─ всё смоделированное
   crew.py      4 вымышленных астронавта (личные базы)
   scenarios.py день 1 (МКС), день 40 (МКС), день 180 (Марс), аномалия (Луна, день 60)
   simulator.py история по тем же кривым NASA + аномалии + шум; доза «дозиметра»
 lyra/service.py   сценарии использования (опознание, сеанс, ряд для графика, импорт дозы)
 lyra/server.py    тонкий FastAPI: REST + WebSocket /ws (state, downlink)
 lyra/dashboard    чистый JS без сборки: app.js (поток сеанса, график, очередь, голос),
                   body3d.js (Three.js 0.160.0 с CDN — облако точек тела)
 lyra/feasibility  реальная камера (MediaPipe, rPPG) и ESP32 — проверка осуществимости, демо не импортирует
```

**Решения**
- *Коридор NASA.* База — среднее 7 дней до полёта. Полуширина = `band` из справочника, но не уже 2σ шума датчика
  (иначе шум выглядит как «быстрее NASA»); без `band` — max(2σ, ½ ожидаемого изменения).
  `model: none`, `rate: 0` или нечисловые поля → коридора нет, только личная норма.
- *Комбинация статусов.* Внутри коридора — 🟢 «ожидаемая адаптация» (резкий скачок z≥3 → 🟡).
  Вне коридора в опасную сторону — худший из (коридор: <1 полуширины 🟡, ≥1 🔴) и (z: 2–3 🟡, ≥3 🔴).
  Личная норма считается по остаткам «значение − ожидание NASA», поэтому сдвиг первых дней не даёт ложных тревог,
  а медленный дрейф быстрее NASA ловит коридор, хотя личная норма его «не видит».
- *Поток сеанса* ведёт фронтенд (таймеры, игра, опрос), бэкенд в конце получает `POST /api/sessions`
  и моделирует значения датчиков. Обучающий режим — тот же вызов с `training: true`: ничего не пишется и не отправляется.
- *Время связи.* Задержка — внутри диапазона справочника; для демо ускорена `--time-scale` (по умолчанию ×60), это подписано.
- *Честность.* Всё в UI помечено «смоделированные данные»; формулировки «скрининг, не диагноз»;
  `basis: cited/estimated` и источники показываются рядом с каждой траекторией. LYRA не измеряет радиацию — импорт дозиметра.
